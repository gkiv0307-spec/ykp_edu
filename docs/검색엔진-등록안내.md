# 검색엔진에 사이트 등록하기

페이지를 51개로 늘려놔도 검색엔진이 모르면 소용이 없습니다.
사이트맵을 제출해서 "우리 사이트에 이런 페이지들이 있다"고 알려주는 작업입니다.

**한 번만 하면 됩니다.** 이후 새로 올라오는 물건 페이지는 사이트맵이 매일
자동으로 갱신되므로 따로 손댈 필요가 없습니다.

## 1. 네이버 (먼저 하세요 — 소유확인이 이미 되어 있습니다)

한국 부동산 검색은 네이버 비중이 압도적이라 여기가 가장 중요합니다.

1. <https://searchadvisor.naver.com> 접속 → 우측 상단 **로그인**
2. 상단 **웹마스터 도구** 클릭
3. 사이트 목록에서 **부동산경매.store** 선택
   - 목록에 없으면 아래 "사이트가 목록에 없을 때" 참고
4. 왼쪽 메뉴 **요청 → 사이트맵 제출**
5. 입력칸에 `sitemap.xml` 만 적고 **확인**
   (앞의 주소는 자동으로 붙습니다)
6. "정상 처리되었습니다" 가 뜨면 끝

### 이어서 해두면 좋은 것

**웹페이지 수집 요청** — 새 페이지를 빨리 반영시킵니다.
왼쪽 메뉴 **요청 → 웹페이지 수집** 에서 아래 주소들을 하나씩 넣고 확인하세요.
(하루 50개까지 가능합니다)

```
https://xn--289av8kwmfs4dv2e.store/
https://xn--289av8kwmfs4dv2e.store/apply.html
https://xn--289av8kwmfs4dv2e.store/courses/beginner.html
https://xn--289av8kwmfs4dv2e.store/courses/intermediate.html
https://xn--289av8kwmfs4dv2e.store/courses/advanced.html
https://xn--289av8kwmfs4dv2e.store/courses/coaching.html
https://xn--289av8kwmfs4dv2e.store/courses/consulting.html
```

**검증 → robots.txt** 와 **검증 → 웹페이지 최적화** 도 한 번씩 눌러 보세요.
문제가 있으면 빨간 표시로 알려줍니다.

### 사이트가 목록에 없을 때

1. 웹마스터 도구 첫 화면 입력칸에 `https://xn--289av8kwmfs4dv2e.store/` 입력 → **추가**
2. 소유확인 방법에서 **HTML 태그** 선택
3. 화면에 나온 `content=` 값이 아래와 같으면 이미 사이트에 들어 있으므로 바로 **소유확인** 을 누르면 됩니다.

   ```
   368b5d60cbecc94652dbf0e533bcdf36e3e176ac
   ```

4. 값이 다르면 그 값을 복사해서 Claude Code에게 알려주세요. 사이트에 넣어드립니다.

## 2. 구글 (소유확인부터 필요합니다)

1. <https://search.google.com/search-console> 접속 → 구글 계정(gkiv0307@gmail.com)으로 로그인
2. 왼쪽 위 **속성 추가**
3. 두 가지 중 **URL 접두어** 쪽을 선택하고 아래 주소를 입력 → **계속**

   ```
   https://xn--289av8kwmfs4dv2e.store/
   ```

4. 소유권 확인 화면에서 **기타 확인 방법 → HTML 태그** 를 펼칩니다
5. 이런 태그가 나옵니다:

   ```html
   <meta name="google-site-verification" content="여기에_긴_문자열" />
   ```

6. **`content=` 안의 문자열을 복사해서 Claude Code에게 알려주세요.**
   사이트에 넣고 배포해 드립니다. 그 다음 **확인** 버튼을 누르시면 됩니다.
7. 소유확인이 끝나면 왼쪽 메뉴 **Sitemaps** → 입력칸에 `sitemap.xml` → **제출**
