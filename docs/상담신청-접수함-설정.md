# 상담신청 접수함 설정

사이트의 상담신청 폼(`/apply.html`)에서 받은 내용을 구글 시트에 자동으로 쌓는 설정입니다.
**처음 한 번만** 하면 되고, 5분 정도 걸립니다.

## 접수함 시트

<https://docs.google.com/spreadsheets/d/1Ec1e-LHR97QZMK4i89XMNG3bktYNmN08aF8RZJcx0cg/edit>

신청이 들어올 때마다 이 시트에 한 줄씩 쌓입니다.

---

## 설정 순서

### 1. 시트에서 Apps Script 열기

위 시트를 열고 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
새 탭에 코드 편집기가 열립니다.

### 2. 코드 붙여넣기

편집기에 있던 내용(`function myFunction() {}`)을 **전부 지우고**, 아래를 그대로 붙여넣습니다.

```javascript
/** 사이트 상담신청 폼 → 이 시트로 받기 */

const SHEET_ID = '1Ec1e-LHR97QZMK4i89XMNG3bktYNmN08aF8RZJcx0cg';

/* 시트에 만들 열 순서. 폼 항목 이름과 똑같이 맞춰야 한다. */
const HEADERS = ['신청시각', '이름', '연락처', '관심분야', '경매경험', '문의내용', '물건'];

/* 새 신청이 올 때 알림 메일을 받고 싶으면 아래에 메일 주소를 넣으세요.
   빈 칸으로 두면 시트에만 쌓입니다. */
const NOTIFY_EMAIL = '';

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];

    /* 첫 신청이면 제목 줄부터 만든다 */
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(HEADERS);
      sheet.getRange(1, 1, 1, HEADERS.length).setFontWeight('bold');
      sheet.setFrozenRows(1);
    }

    sheet.appendRow(HEADERS.map(function (h) { return data[h] || ''; }));

    if (NOTIFY_EMAIL) {
      MailApp.sendEmail(
        NOTIFY_EMAIL,
        '[상담신청] ' + (data['이름'] || '이름없음') + ' / ' + (data['연락처'] || ''),
        HEADERS.map(function (h) { return h + ': ' + (data[h] || '-'); }).join('\n')
      );
    }

    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  }
}

/* 브라우저로 주소를 열었을 때 살아있는지 확인용 */
function doGet() {
  return json({ ok: true, message: '접수함이 정상 작동 중입니다.' });
}

function json(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

붙여넣은 뒤 **저장**(💾 아이콘 또는 Ctrl+S)합니다.

### 3. 배포하기

1. 오른쪽 위 파란 **배포** 버튼 → **새 배포**
2. 왼쪽 톱니바퀴(⚙️) → **웹 앱** 선택
3. 아래처럼 설정합니다:

   | 항목 | 선택할 값 |
   |---|---|
   | 설명 | 아무거나 (예: 상담신청 접수) |
   | 다음 사용자로 실행 | **나 (본인 계정)** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** ← 꼭 이걸로 |

4. **배포** 누르기
5. 권한 요청이 뜨면 → **액세스 승인** → 본인 구글 계정 선택
6. "Google에서 확인하지 않은 앱" 경고가 나오면
   → **고급** → 맨 아래 **'제목(안전하지 않음)'으로 이동** 클릭
   (본인이 직접 만든 스크립트라 안전합니다)
7. **허용** 누르기

### 4. 주소 복사해서 알려주기

배포가 끝나면 **웹 앱 URL** 이 나옵니다. 이렇게 생겼습니다:

```
https://script.google.com/macros/s/AKfycb.................../exec
```

이 주소를 복사해서 Claude Code에게 알려주세요. 사이트에 연결해 드립니다.

## 확인하는 법

복사한 주소를 브라우저 주소창에 그대로 붙여넣고 열어보세요.
아래처럼 나오면 정상입니다.

```json
{"ok":true,"message":"접수함이 정상 작동 중입니다."}
```

## 나중에 코드를 고쳤다면

Apps Script에서 코드를 수정한 뒤에는 **배포 → 배포 관리 → 연필(✏️) → 버전: 새 버전 → 배포**
를 해야 반영됩니다. 저장만 해서는 사이트에 적용되지 않습니다.
(주소는 그대로 유지됩니다.)

## 알림 메일도 받고 싶다면

코드 위쪽의 이 줄을 고치고 **새 버전으로 다시 배포**하면 됩니다.

```javascript
const NOTIFY_EMAIL = 'gkiv0307@gmail.com';
```
