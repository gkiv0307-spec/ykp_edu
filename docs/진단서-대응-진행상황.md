| 항목 | 처리 |
|---|---|
| `title`/`description`/og 의 "자산 250억&낙찰 300억" | 무엇을 파는 곳인지 그대로 적는 문장으로 교체 |
| 히어로 `h1` 숫자 자랑 | "대구 수성구 오프라인 경매교육" + 초급 5주 33만원·법원 현장수업 |

| "023초 과정 찾기" | 모바일 메뉴에서 순번 `02` 와 `3초 과정 찾기` 가 붙어 읽히던 문제. "내 과정 찾기"로 변경 |
| 중복 물건 | 2025타경1098·2025타경9934 각 1건 제거(46→44). `update-listings.mjs` 에 사건번호 기준 중복 제거를 넣어 재발 차단. 진행중 탭 34→32 |

## 게시 전 확인 — 대표님만 아는 값

아래는 추측으로 채우면 안 되는 값이라 **비워 두었습니다.** 알려주시면 바로 넣겠습니다.

1. 첫 입찰 준비반 / 권리·수익분석 실전반의 **총 교육시간** (현재 "5주 과정"만 표기)
2. 실행코칭의 숫자 — 월 분석보고서 건수, 개인상담 횟수·시간, 입찰가 검토 횟수,
   조건에 맞는 물건이 없는 달의 처리, 낙찰 후 지원기간, 중단·일시정지 가능 여부
3. **환불·연기·결석·영상복습·질문기간** 규정 (2주 과제 3번)
4. 수강생 낙찰 사례 5건 — 사건번호·낙찰가·수강 기수·동의 여부 (2주 과제 1번)
5. "낙찰률 95%" 를 대체할 **평균 낙찰가율**
6. 다음 기수(21기) **개강일과 잔여석** (최우선 10번)
7. 실적 집계 **기간** (현재는 무엇을 센 숫자인지만 밝힌 상태)
