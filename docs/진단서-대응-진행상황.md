### 값만 채우면 바로 공개되는 것

두 파일의 `null` 을 채우고 `node scripts/build-static-pages.mjs` 를 실행하면 됩니다.
채우지 않으면 해당 항목은 **페이지에 아예 나오지 않습니다.** 확정되지 않은 내용이
그럴듯한 모습으로 공개되는 일은 없습니다.

- `data/policy.json` — 연기 / 결석 / 영상복습 / 개인정보 보유기간 / 보호책임자
- `data/schedule.json` — 21기 개강일 · 요일시간 · 정원 · 잔여석

빌드할 때마다 아직 못 채운 항목의 이름을 콘솔에 찍어 알려줍니다.

### 확인이 필요한 것

- **평생직업교육학원 등록 여부.** `/policy.html` 의 환불 표는 학원법 시행령 별표4
  기준을 근거와 함께 실었습니다. 등록 학원이 아니라면 근거 문장을 빼고 자체 기준을
  적어야 합니다.
- 첫 입찰 준비반·권리·수익분석 실전반의 **총 교육시간** (지금은 "5주 과정"만 표기)
- 첫 낙찰 실행코칭의 숫자 — 비교표에 "계약 전 서면 안내"로 적혀 있습니다

## 알아둘 것

- `index.html` 은 **한 줄로 압축된 단일 원본**입니다. 과정 카드·헤더·푸터를 여기서
  읽어 하위 페이지를 만들기 때문에, 카드 구조(`course-title`, `course-support` 등)를
  바꾸면 `scripts/lib/courses.mjs` 의 파싱도 함께 봐야 합니다.
- `main` 의 자동 워크플로가 매일 `index.html` 을 다시 씁니다. 한 줄 파일이라 이
  브랜치와 항상 통째로 충돌합니다. 병합할 때는 물건 목록을 main 것으로 받고 문구·과정
  부분만 다시 얹으세요.
- `scripts/update-listings.mjs` 의 중복 제거가 main 에 들어가기 전까지는 자동 갱신이
  중복 물건을 계속 되살립니다.
